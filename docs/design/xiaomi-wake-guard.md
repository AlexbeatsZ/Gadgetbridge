# S4 保持清醒

## 范围与入口

用户要求 Dayweave 手表图标补圆形边框；手动配置每周非睡眠时段，在固件报告疑似睡眠后按时段振动或响铃。应用名 Shale 是口误，本功能没有 ICS 订阅。监测和规则由手机 Gadgetbridge（显示名「手环」）管理，入口是 S4 设置 → 保持清醒；不依赖 Dayweave 前台。

手机列表和编辑必须沿用统一 Pixel 设置：`AbstractSettingsActivityV2`、`AbstractPreferenceFragment`、`activity_settings`、动态取色 Material 开关、对话框和时间选择器；草稿仅保存后落盘。默认关闭、没有预置作息，最多32条规则，名称/启停/星期/起止时间/提醒方式/1–30分钟确认时长。旧 JSON 的 repeat 参数保留兼容，但界面不再提供固定间隔重响，它不控制关闭后本轮重新确认。

## 用户确认的循环（2026-11-27）

最终要求已从“必须等待关闭回传”放宽为：发现仍在睡觉时可以重复请求原生闹钟/铃声，不必把关闭回执作为前置条件。继续使用每周规则、确认时长和重复间隔。清醒后不再发送新请求；已在手表起响的提醒由用户关闭，应用不自动停止或删除闹钟。

响铃由 `XiaomiWakeGuardClock` 复用一个表内一次性普通闹钟。先读最新列表，第一次创建、以后更新同一个实际ID，再查询确认。S4只有小时/分钟，安排下一个整分钟，最多约60秒起响延迟。未完成的同类请求合并，不不停新增闹钟。所有权按ID和读回配置匹配，enabled和设备计算的nextRingTimestamp不参与匹配；用户改动或删除后放弃该槽，不能覆盖用户修改。其他闹钟距当前±2分钟时避让。已满时报告无槽位，不删除用户闹钟。

创建前持久化旧ID集合和目标时间；ACK丢失/断连后按唯一新增匹配恢复，避免重复创建。编辑前保留目标身份，读回或下次查询再恢复。模糊状态不自动覆盖/删除项目。断连清理当前事务，无排队的提醒在重连后突然下发。创建和通用闹钟编辑互斥，其他编辑排队到读回后处理。

纯振动使用原生PhoneAlarm ALERT，即时出现原生振动界面；持续睡眠的下一次提醒可重复ALERT，不要求先关。关闭回传仅释放可用所有权，不控制监测循环。没有Dayweave/vibrator中转，也没有手机播放器。

## 数据与时间

复用 Xiaomi type2/subtype78 `BasicDeviceState` 和 subtype79 可选状态更新。仅已开启、命中规则且没有未关闭提醒时，每30秒主动查询。至少两次睡眠上报、持续达到确认时长，睡眠/佩戴/充电三项均在90秒内，且佩戴、未充电才触发。不用静止、低心率或历史睡眠文件推断实时入睡。部分更新不刷新其余字段；数据缺口、时间倒退、清醒、摘表、充电或时段结束清空候选。定时器只能使数据过期，不能补造睡眠样本。

星期周一为bit0，起点含/终点不含；跨午夜归开始日，下一天的独立时段重新确认。起止相同无效。使用进程默认时区（包含用户已有自定义时区），确认用单调时钟。重叠时响铃优先，其余按规则列表顺序。

**S4 3.201.79 实机边界：本轮两次 type2/78 查询仅看到链路ACK，没有收到实时睡眠响应。自然睡眠分类是否由79推送、能否满足新鲜度尚未验证。状态为等待数据时不会提醒；不能把管理器模拟样本测试当作实机睡眠识别成功。**

## 原生提醒渠道与所有权

纯振动 type17/subtype16（ALERT0/DISMISS1/SNOOZE2），实机用户确认有原生界面和振动、没有声音；匹配本功能ID的关闭/稍后提醒释放对象。真实手机闹钟接管只放弃本功能所有权，不发DISMISS，避免S4共用闹钟页面误停真实闹钟。

响铃 type17/subtype1创建、2更新、0读回，使用表内预置声音；最终功能不发删除命令，也没有自动停止。S4 3.201.79 的本地闹钟ID从0开始，编辑/启停/删除映射与导入必须一致；其他型号保留原1起始映射。零ID不能当失败。普通一次性闹钟在起响时即变为enabled=false；不能据此断言用户关闭。

原先考虑寻找手表2/18的关闭回传，用户随后明确接受重复请求，不再引入回传门控。真实手机闹钟、外部寻找和 Sleep as Android 运行时不发新提醒。

本轮20:08本地闹钟探针ID0按用户要求保留（最后读回禁用）；不将禁用当作关闭证据。

## 手机铃声实验结论

用户希望把熟悉的手机铃声文件传到表本地播放，并表示官方不支持就算了。小米官方S4 FAQ明确不支持自定义铃声，只能预置。此前尝试经HFP/SCO播放 Jump-Start，日志虽显示设备路由，用户连续确认只有振动，已从交付源码撤回播放器和选择器；不得继续宣称已成功播放手机铃声。
